# G検定 学習ツール

JDLA（日本ディープラーニング協会）ジェネラリスト検定の対策用Web学習ツールです。

## 使い方

1. `index.html` をブラウザで開く
2. 学習モード（問題数）を選択
3. 出題カテゴリを選択（未選択で全カテゴリ）
4. 「学習スタート」をクリック
5. 選択肢を選ぶと正誤と解説が表示される
6. 全問終了後、カテゴリ別の結果を確認できる

## 機能

- **問題数選択**: 10問 / 25問 / 50問 / 全問
- **カテゴリフィルタ**: 苦手分野を集中学習
- **回答済み/未回答トラッキング**: 各問題の回答状況を記録し、「未回答のみ」「回答済みのみ」のフィルタが可能
- **進捗表示**: カテゴリごとの回答済み問題数をバッジで表示
- **ランダム出題**: 毎回異なる順序で出題
- **即時フィードバック**: 回答直後に正誤と詳細解説を表示
- **結果サマリー**: カテゴリ別の正答率をグラフで表示
- **間違えた問題の復習**: 不正解の問題だけを再出題
- **学習履歴**: localStorage でカテゴリ別の累計成績を保存
- **キーボードショートカット**: 1-4 / a-d で回答、Enter / Space で次へ

## 技術構成

- HTML / CSS / JavaScript のみ（単一ファイル）
- 外部依存なし
- ローカルで動作（サーバー不要）
- レスポンシブ対応（スマホ・タブレットでも利用可）

## 注意事項

- 本ツールは非公式の学習補助ツールです
- 問題は実際の試験問題ではなく、シラバスに基づいて作成した練習問題です
- 最新の出題範囲はJDLA公式サイトをご確認ください
